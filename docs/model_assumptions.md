# Model Assumptions

1. Each process can be handled by one workstation at a time.
2. A workstation can process only one operation at a time.
3. Equipment health decreases after processing work and recovers after maintenance.
4. If equipment health reaches the failure threshold, corrective maintenance is required before more work can continue.
5. Preventive maintenance is triggered by a fixed interval or health threshold.
6. Transportation time between workstations is ignored in the initial model.
7. Processing time is deterministic in the baseline model and can be extended to stochastic distributions.
8. Orders are available at simulation time zero unless a release time is explicitly added later.
